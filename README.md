# Лабораторная работа №4: Обработка массивов

## Автор
Иванова Ксения 
Группа: ПИ-261

## Вариант
Вариант 6

## Описание
Программа обрабатывает квадратную матрицу. В каждой строке матрицы находится наибольший элемент, после чего он меняется местами с соответствующим элементом главной диагонали. 

## Входные данные
1. Размер квадратной матрицы (целое число от 1 до 20).
2. Элементы матрицы (целые числа от -1000 до 1000), вводятся построчно.

## Выходные данные
1. Исходная матрица в общепринятом табличном виде.
2. Измененная матрица (после перестановки максимальных элементов с диагональю) в табличном виде.
